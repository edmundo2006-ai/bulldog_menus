# Yapp Support

Thank you for using **Yapp** (previously Bulldog Menus).

Yapp is an independent app built by a Yale student for Yale students. It covers:

- **Dining** menus, hours and nutrition for every residential college and dining hall
- **Butteries**, including opening status and ordering
- **Shuttle** tracking with live bus positions and trip planning
- **Jobs** and fellowships from Yale's own listings
- **Birthdays**, a Yale-only student directory

## Privacy

[View our Privacy Policy](https://edmundo2006-ai.github.io/bulldog_menus/privacy)

The Birthdays directory is built from the Yale Face Book and Yale Directory, both of
which require a Yale login. Nobody in it opted in, so anyone in it can take themselves
out.

**To remove yourself:** open Settings in the app, find "Your directory entry", and tap
"Remove me from Birthdays". Your entry disappears immediately and stays gone when the
directory is next refreshed from Yale.

Because the directory only works if it is mutual, removing your entry also closes the
directory to you until you opt back in. You can do that from the same screen at any
time.

**If you cannot use the app**, email **edmundo20061@gmail.com** and your entry will be
removed by hand.
